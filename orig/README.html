Calendrical Calculations

CD Contents

This compact disk accompanies the book Calendrical Calculations: The Millennium Edition by Edward M. Reingold and Nachum Dershowitz (Cambridge University Press, 2001).

For more information see the site

http://www.calendarists.com


The Calendrica folder on this CD contains the following folders and files:

  1. Calendrica.html [the Calendrica Applet]

    2. Viewing the applet requires a Java-enabled browser or an applet viewer.
    If you are using a Macintosh, make sure you have a full Java runtime environment (click for download) and that your browser is using it (click to obtain required Netscape MRJ plugin).
  2. Mac.html If your Macintosh browser still fails with the full applet, use this version instead.
  3. Warnings.html [warnings regarding the accuracy of the code and applet]
  4. Lotus.html [pointer to a Lotus implementation]
  5. Lisp [Lisp source]
  6. Mathematica [Mathematica source]
  7. Java [Java source]
  8. Dates [tab-separated sample dates]
  9. Names [names of months, etc.]

    10. Full viewing of foreign languages requires Unicode fonts.
  10. Fonts [Unicode font for PCs]
